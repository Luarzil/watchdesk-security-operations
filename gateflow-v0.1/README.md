# GateFlow V0.1

Static HTML/CSS/JS prototype for a Zebra TC22R-style Android handheld gate scanner and desktop manager dashboard.

Open `index.html` directly or run `OPEN-GATEFLOW.cmd`.

Demo scanner fields accept typed values or the `Sim scan` buttons. Demo supervisor IDs include `SUP-1001` and `SUP-2040`.

The app stores prototype data in browser `localStorage`. Use `Reset demo` to restore the seeded data.
