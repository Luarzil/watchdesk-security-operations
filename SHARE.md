# Sharing WatchDesk

The preferred sharing setup is:

1. Push this folder to a GitHub repository.
2. In Vercel, import that GitHub repository.
3. Keep Vercel defaults for a static project:
   - Framework preset: `Other`
   - Build command: blank
   - Output directory: `.`
4. Share the Vercel production URL with Patrick.

The root `index.html` is the interactive app Patrick should see.
