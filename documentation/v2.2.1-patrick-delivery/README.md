## Core Check-In Rule

An hourly check-in updates the Guard Timeline, Admin Dashboard, live activity,
and Payroll check-in count.

- `All normal` does not create a supervisor queue item.
- `Need supervisor` adds a Top Priority request and can move payroll to Review.
- Neither choice automatically creates a DAR or IR in Reports.
- Payroll gross pay remains based on each guard's hours and individual wage.
