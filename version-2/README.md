# WatchDesk V2 Preview

This folder is a second, separate preview built from `deep-research-report (2).md`.

Open `OPEN-WATCHDESK-V2.cmd` or `index.html` to preview it.

The V2 preview focuses on the new data structure:

- shifts as the source of operations and payroll,
- check-ins as first-class rows,
- report entries instead of only local activity arrays,
- incidents as reviewable objects,
- payroll line items with approval status,
- exports with storage paths and checksums,
- audit events for critical actions,
- roles for UL, CFSL, CML, CAL, ARUL, SA, and Lori as a finance reviewer assignment.

This is still a static browser prototype. It does not include Supabase, Auth, RLS, Stripe, email, or server PDF generation yet.
