# WatchDesk Simple V2

This is a simpler Patrick-facing preview.

Open:

- `OPEN-WATCHDESK-SIMPLE.cmd`
- or `index.html`

This version intentionally hides the heavy technical architecture and focuses on:

- Office dashboard
- Guard phone workflow
- Hourly check-ins
- DAR / IR notes
- Supervisor queue
- Payroll review
- Printable reports

The underlying demo still follows the research direction: shifts, check-ins, reports, incidents, payroll rows, and exports.
